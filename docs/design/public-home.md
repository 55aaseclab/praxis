# 公开产品主页

设计提案 · 2026-11-20 · [English](public-home.en.md) · [中文原型](public-home.zh-CN.html) · [英文原型](public-home.en.html)

## 目标与范围

通过搜索进入的人应能看懂 Praxis 是什么、看到真实的 agent → 应用过程，再选择在线试用或自托管。已有用户直接进入工作台。这是公开产品介绍页，和登录后的日常工作界面分开。

本提案不增加生产路由或域名。官网 origin 尚未确定，现有工作台和登录保持原址。设计原型明确标记 `noindex`；正式索引版本须先确定生产 origin。

## 视觉方向

沿用产品原生系统字体与应用图标，以白底、深色文字和松绿色操作为主。记忆点是现有真实 Paseo / Praxis 四帧演示，Reminder 使用合成内容，不重新编造聊天界面。默认显示静态图，用户主动播放/暂停，减少动态效果时保持静态。没有虚构客户、用户量、GitHub 星数或装饰性仪表盘。

| 元素 | 设计 |
| --- | --- |
| 颜色 | 白 `#ffffff`；正文 `#252529`；辅助文字 `#606069`；分隔线 `#e1e5e6`；松绿 `#20584d`；浅底 `#f1f4f5` |
| 字体 | 系统无衬线，中文使用 PingFang / Microsoft YaHei；不依赖远程字体 |
| 字号 | 首标题英文桌面64px/手机38px，中文54/32px；节标题36/28px；正文17px、1.65行高 |
| 布局 | 最大1160px，桌面32px/手机20px边距；内容左对齐，留出节间空间，不堆同款卡片 |

初稿考虑过三张并排的卖点卡片，现删去：真实演示和实际应用目录更能说明 Praxis 的特点。编号仅用于确实有顺序的三个接入步骤。

## 页面结构与文案

1. 顶部：Praxis、应用、开始使用、GitHub、语言、打开工作台。
2. 首屏：**为你的 AI 智能体，准备一个自己的工作台。** 说明“说出想要的结果，选择允许访问的内容，再到应用里查看和使用结果”；两个入口为“用你的智能体试试”和“自行部署 Praxis”。
3. 真实演示：左侧 Paseo，右侧 Praxis，静态图与主动播放控制。
4. 三步：表达需求 → 登录授权 → 查看结果。强调保护使用者注意力，不承诺所有工作流已做到零点击，不引入员工监督。
5. 内置应用：十四个已发布组件的真实图标、名称、简短用途、公开源码链接；Polaris 标明运行观察，不作为业务卡片。
6. 自己掌握工作：自己的数据、可查的操作线索、自建应用，适用于个人、家庭、团队与组织。
7. 在线试用与自托管：分开说明，最后是始终展开的常见问题和文档入口。

在线试用复制 README 的 OAuth prompt，由用户登录并选择授权，再执行具体 Reminder 示例。明确需要已有账号，开放注册仍在计划中，不放虚假注册按钮。本地部署启动完整十四应用 Compose 栈，读取生成账号，再连接本机 MCP。实际开发时从受审应用注册表生成展示目录，不再制造一份权威应用清单。

## 交互与可访问性

导航与源码使用普通链接。复制只改变固定图标槽和隐藏的无障碍播报，不插入“已复制”一行、不跳布局、不弹 toast；失败时保留可手选文本。演示有明确播放/暂停状态和可访问名称，无 JavaScript 时仍能看静态图。保留焦点、最小44px点击区域，手机应用目录为两列，正文与 FAQ 不折叠，页面不横向溢出。

## SEO 与分享

| 项目 | 正式页面设计 |
| --- | --- |
| 英文标题 | `Praxis — A self-hosted workbench for your AI agent` |
| 中文标题 | `Praxis — 为你的 AI 智能体准备的自托管工作台` |
| 描述 | 用普通语言说明自选 agent、授权应用操作、查看结果、自托管或在线试用 |
| URL | 确定官网 origin 后，英文 `/`、中文 `/zh-cn/`，分别 self-canonical，双向 `hreflang=en/zh-Hans/x-default` |
| 正文 | 匿名200、预生成语义 HTML、H1/H2 和可抓取链接；不能只靠 JS 翻译正文或强制按浏览器语言跳转 |
| 发现 | sitemap 收录两个正式 URL 和实际更新时间，robots 允许公开页 |
| 隐私 | 登录及业务数据保持鉴权，robots/noindex 不代替权限保护 |
| 结构化数据 | 使用真实且和正文一致的 `WebSite` / `SoftwareSourceCode` 信息，不虚构价格、评分、评论或承诺富结果 |
| 分享与性能 | 双语 OG 文案、真实合成数据产品图、尺寸和 alt；正式绝对 URL 来自配置。首屏静态图、用户触发动画、下方图标懒加载、不阻塞远程字体 |

独立官网 origin 可避免移动现有 Calendar/Matrix 浏览器状态及 OAuth 回调。如以后同源部署，须先确定根路径/工作台路径和兼容方案，不悄悄替换当前根入口或新建另一套安装。

依据：[Google SEO 入门](https://developers.google.com/search/docs/fundamentals/seo-starter-guide)、[多语言页面](https://developers.google.com/search/docs/specialty/international/localized-versions)、[结构化数据要求](https://developers.google.com/search/docs/appearance/structured-data/software-app)。这些做法不保证收录、排名或富结果。
