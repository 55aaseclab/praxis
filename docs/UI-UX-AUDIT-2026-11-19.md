# Praxis UI/UX 审计 · 2026-11-19

[English](UI-UX-AUDIT-2026-11-19.en.md) · 简体中文

依据[平台 UI/UX 设计指南](UI-UX.md)，本轮覆盖工作台、登录、管理、PRD 阅读、系统导航及应用登记表中的十个应用。检查从用户的具体目标开始，包括打开指定对象、找到资料、修改后保存、返回、断网重试和仅用键盘完成操作。

下表中的 P1 表示会阻断任务、打开错误对象、误报完成或丢失输入；P2 表示任务仍可完成，但定位、反馈或操作方式造成障碍。每行记录这次走查发现的行为和相应验收点。

## 平台界面

| 范围 | 复现操作与问题 | 修复后可观察的结果 |
|---|---|---|
| P1 登录与系统导航 | 从带项目或段落定位的链接重新登录，或输错一次密码再登录，原目标丢失。 | 提示错误的页面直接保留账号和已校验的站内目的地，密码留空。重新登录后回到原对象及位置。 |
| P1 工作台退出 | 服务暂时不可达时点击退出，界面仍跳到登录页，使用者以为会话已结束。 | 点击后先收起私人内容；退出得到确认才跳转。结果未确认时可以重试退出或重新读取账号。 |
| P2 工作台读取与直接访问 | 账号请求失败时唯一入口是登录；已登录用户直达无权限的应用可能看到一段 JSON。 | 未确认会话时提供重新读取。浏览器打开受限页面会看到可理解的状态和返回工作台入口；API 继续返回协议错误和原 HTTP 状态。 |
| P1 管理表单 | 填写账号或权限后切出再切回，前台刷新重建表单；管理请求超时没有反馈。 | 当前身份和权限复核通过后保留已输入的草稿。读超时提示重试；写超时提醒先刷新核对是否已保存。 |
| P2 管理确认与反馈 | 键盘打开停用确认后焦点默认落在确认，取消后找不到原按钮；复制数据位置的结果仅在鼠标提示中。 | 确认区默认聚焦取消，Esc 关闭后焦点返回触发控件；复制成功和失败有可见、可播报的文字，失败时可手动复制。 |
| P2 PRD 阅读 | 在手机上展开长文目录，条目只按文字行高响应点按。 | 目录链接有至少 44 CSS px 的点按高度，选中后跳到对应标题。 |

## 应用界面

| 应用 | 复现操作与问题 | 修复后可观察的结果 |
|---|---|---|
| Reminder · P1/P2 | 首次读取目录失败后点重试没有响应；键盘切换分类后焦点丢失。 | 受管入口重新读取会话和目录；独立版与受管版切换分类都保留键盘焦点。 |
| Knowledge · P1/P2 | 按已导入原件的文件名搜索无结果，后台刷新会覆盖未提交的搜索词。来源或项目引用读取失败时也可能显示重复状态或空引用。 | 能按原件标题、文件名找到并打开资料，刷新保留搜索词。来源可重新读取，引用暂不可读时提示覆盖不完整。 |
| Projects · P2 | 展开一项工作并切回前台，后台复核会收起详情并移走焦点。 | 当前项目刷新后，仍存在的工作项维持展开，键盘焦点保留在对应控件。 |
| Memo · P1/P2 | 分类、场景、清单和照片依赖鼠标；迟到的档案响应可能清除刚勾选的内容；指南读取失败后无法直接重试。 | 键盘可进入场景、操作清单和打开照片；Esc 关照片并回到原处。后台读回保留本次勾选，指南可就地重试。 |
| Finance · P1 | 账本版本冲突后，重新读取按钮被编辑弹窗挡住；单击删除立即改账。切换视图、月份后浏览器后退无法恢复原筛选。 | 弹窗内可重新读取、核对并保留输入再次保存；取消删除保留流水。后退、前进及刷新可恢复链接所指的视图和筛选。 |
| Intelligence · P2 | 材料列表用按钮模拟链接，对比和目录跳转后键盘焦点停错位置。 | 材料可用原生链接打开；更换对比对象、返回列表及选择目录标题时，键盘能从目标位置继续。 |
| Travel · P1 | 详情页的分类统计请求失败后，「全部路线」只显示当前路线，用户无法从详情返回完整目录。 | 获准的完整目录入口独立于计数请求；统计暂不可用时仍能返回目录，再后退到原行程日。公开分享继续仅显示该行程。 |
| Lattice · P1/P2 | 矛盾或失效的文稿深链接可能回落到另一对象；读取失败和确实没有文稿难以区分。 | 按空间和资源打开指定文稿；失效链接可返回列表，临时失败可重试，空目录有明确提示。Esc 关闭菜单后恢复焦点。 |
| Polaris · P1/P2 | 首次打开设置也要等整份运行历史（审计时约 3.52 MB），首次失败后无法就地重试；工作流节点可聚焦却不能用键盘选择。 | 工作区授权通过即呈现导航。运行历史仅在工作及运行页面读取，有加载、失败和重试状态；读取中可去设置页。Enter 或空格可选择图节点，修饰键可打开新标签。 |
| 听校 · P1 | 快速选择两份字幕或两个项目时，迟到结果可能替换当前选择；项目请求失败与空历史同时显示。受管任务保存期间仍可继续编辑，后续清空草稿。 | 最新选择生效，失败与空历史区分。受管页首次连接、任务列表失败均可就地重试。提交中的校正暂时只读，失败恢复草稿；结果未确认时先回读，权限失效则清理当前任务。 |

## 验证范围

- 修复使用合成账号、账本、项目、字幕和文稿。浏览器交互覆盖了失败后纠错、慢响应与切换、冲突后重新读取、取消和键盘焦点。迁移前的 Chromium 回归覆盖了平台登录、返回与退出顺序。
- 线上另做登录后的只读入口巡检，观察响应、浏览器异常和窄屏整体溢出。页面返回 200 与具体业务任务通过分别记录，首屏控件数量不作为可用性评分。
- 发布后在正式入口使用只读浏览器检查工作台、管理、PRD 与十个应用。13 个入口均返回 HTTP 200，能呈现对应页面；390px 和 1280px 视口均未检出整页横向溢出。首次并发巡检中，工作台、管理和 PRD 未全部就绪，分别重开后通过。
- 390px Chromium 代表窄屏浏览器。实体手机、读屏软件逐项朗读、外部地图服务、真实音视频导出，以及所有历史数据和角色组合，仍需在相应环境单独验证。
