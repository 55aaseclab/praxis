Travel was retired from the Praxis distribution on 2026-11-25 (platform release v0.1.160). The application repository `github.com/55aaseclab/travel` was deleted at the same time.

Travel is no longer part of the installed distribution, the workbench, the app catalog or the OAuth/MCP consent surface. Historical release rows and verification ledger entries that mention Travel remain as history. Existing installations keep their own working data: `itineraries/travel.db` and `content/` stay where the owning installation stored them.
