Reminder is no longer part of the installed distribution, the workbench, the app catalog or the OAuth/MCP consent surface. Historical release rows and verification ledger entries that mention Reminder remain as history and are not updated. Existing installations keep their own working data: the app-owned `reminder.db` (structured records) and any legacy space JSON sources stay where the owning installation stored them.
