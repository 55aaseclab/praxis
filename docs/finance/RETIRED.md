# Finance retired

Finance was retired from the Praxis distribution on 2026-11-25 (platform release v0.1.157). The application repository `github.com/55aaseclab/finance` was deleted at the same time.

This directory preserves the app's final public documents from release `0.1.3` at source commit `7f6c950c0d95ec5bb123aade6fc8c7b62887888e`:

Finance is no longer part of the installed distribution, the workbench, the app catalog or the OAuth/MCP consent surface. Historical release rows and verification ledger entries that mention Finance remain as history and are not updated. Existing installations keep their own working data; the former `finance.db`/`finance.json` sources stay where the owning installation stored them.
