# 设置中的状态概览

[English](PLATFORM-STATUS.en.md) · 简体中文

「设置 → 状态概览」向平台管理员展示权限控制、连接及业务数据存储；普通用户不显示或请求这组全局信息。每组给出检查时间；未知、不可用、过期和处理中分别显示。页面每30秒或点击刷新时重新读取，不执行备份、同步或权限修改。平台入口统一见[平台手册](PLATFORM.md)。

概览采用本地Chart.js与原生表格呈现：数量、覆盖和聚合耗时使用图形，连接/副本状态、时间、范围与口径使用表格，每张图有对应数值表。体验线索覆盖既有全部聚合分组；没有采集到的历史不绘成趋势，未知或过期也不补零。刷新、切页或失效时清理图表，库不可用时仍可读表格。图表资源走固定同源路径，不向第三方服务发送数据。

## 只读访问

从工作台点击「设置」进入 `/admin/` 的「通用」页。管理员可选择「状态概览」查看 MCP 调用 Trace；「使用与体验线索」始终展开。工作台首页不展示或请求这些内容。平台管理员还可切换用户、入口权限和智能体委托；普通成员可在设置中选择语言并查看自己的权限与委托，全局概览仅管理员可读。

沿用平台身份登录，仅显式平台管理员可查看。服务端`canViewPlatform`仅反映管理员身份，接口自身再次验权；不保留`console.viewers`单独授权或兼容入口。非管理员、停用或过期会话、其他客户端会话及业务Bearer不能读取。退出、会话失效或查看能力收回时清空详情，不保存到浏览器存储。

原生HTTP入口和规范HTTPS登录域遵守各自的浏览器cookie边界，不降低Secure cookie要求。需要使用规范HTTPS工作台完成登录查看；公网认证链路不可用时，不能将隔离浏览器验收当作实际手机访问成功。

## 配置与运行

私有核心后端配置增加可选的`console`：

```json
{
  "console": {
    "storageStatusFile": "/private/praxis/platform-status/storage.json",
    "storageConfigFile": "/private/praxis/config/storage.json"
  }
}
```

输出目录必须独立、位于Git外且权限700，JSON文件权限600。配置由既有栈命令校验；配置错误不自动创建业务数据。核心后端只读挂载脱敏输出目录，网页进程不挂载存储配置、密钥、原始业务文件或Docker socket。

新增存储状态发布服务只读现有配置、仓库结果和后台心跳，写入固定字段投影；无网络连接，不触发云请求。发布器与原有存储后台任务分开管理，更新管理界面不需要重启正在执行的备份。

网页通过固定本机上游代理访问只读接口：

- `/api/platform/status` → `/api/business/console/status`
- `/api/platform/observations?window=day|week` → 同名业务控制台聚合接口

代理只转发指定浏览器身份cookie，拒绝调用者Authorization及跨源请求，不接受目标URL参数，不跟随重定向，限制响应大小和等待时间；响应不缓存。

## 读数含义

- 权限覆盖只统计已接入统一业务控制的应用；其他应用仍保留自己的访问控制。未到期委托不等于其每个动作仍获许可。
- 服务探针只证明最近一次服务可达；业务适配配置与MCP实际调用另行呈现，不虚构“在线agent”。
- 本地快照、云端复制、完整性检查各有自己的时间。读到新的本地状态文件不代表刚刚验证过云端。
- 副本与最近本地快照一致不保证所有最新业务变化已经上云。处理中或排队时明确标注；缺少成功覆盖收据时显示未记录。浏览器导出、原始音频及恢复密钥仍需单独保全。
- 最近一天/七天的体验记录来自脱敏观测库；浏览器样本不作为可信业务成功或独立用户数。能力缺口只是待人工复核的需求线索。

## Trace 中的 MCP 调用

Trace 默认打开 **MCP 调用**。日／周汇总与工具分布由该窗口内实际记录的全部调用计算，不拿当前页的行数代替总量。每条调用展示已注册工具或安全的未知／控制类别、结果、耗时及脱敏调用者引用，并可继续查看已记录的授权、应用执行、提交和回读。任务受理不等于后台任务已完成，HTTP 成功也不等于工具成功。

原生管理员会话通过 `GET /api/platform/traces?source=mcp&window=day|week` 读取。运行观察、生命周期历史、授权决定和应用变更仍是独立可选来源。Polaris 只补充工作流上下文，不提供 MCP 调用量。历史资料不反填为工具调用，界面明确记录起点。切换来源及分页不扩大业务记录权限。
