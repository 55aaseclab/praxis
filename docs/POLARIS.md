# Polaris 工作区与数据

[English](POLARIS.en.md)

## 工作区身份

Praxis 存储使用工作区标识区分各套安装。默认工作数据根目录为 `<dataRoot>/workspaces/<workspaceId>/apps/polaris`。可以用 `workingData.roots.polaris` 登记其他根目录。既有安装还可能使用独立的持久存储键来标识归档、签名或断点。迁移存储时两个标识都要保留。管理员使用的查看器会检查观察文件中的工作区标识。

## 数据归属与恢复

| 数据 | 恢复核验 |
| --- | --- |
| 工作区绑定与私有配置 | 保留工作台工作区与持久数据的对应关系；原始配置和回滚资料一起私有保存。 |
| 运行历史与断点 | 保留原始存储，将已授权学术运行的标识、时间和状态与查看器投影逐一比对，包括失败的运行。 |
| 归档与导出 | 原始文件、签名与密钥继续受数据所有者的权限控制。切换活动绑定前先核对副本完整性。 |
| 查看器投影 | 只读挂载一个仅所有者可访问、工作区标识匹配的文件。可由获授权的数据来源重新生成。 |
| 展示界面 | 平台固定独立查看器的源码版本，可按登记的提交重新构建静态界面。 |

早期安装分别保存控制数据库、工作区绑定、归档、导出、采集断点及私有客户端状态，各类数据需分别考虑恢复方式。活动数据库使用一致性备份，并保留原工作区关联。当前受管查看器只需读取指定的观察投影。原始归档、客户端状态、令牌与凭据存放在 Git 和查看器容器之外。

## 运行与验收

管理员从 `/apps/polaris/` 进入，独立入口将本机服务绑定在 `127.0.0.1:18787`。每次读取接口时会校验观察文件。使用原子替换更新文件后，需要重新创建只读挂载来指向新的 inode。验收时核对工作区标识、各类终态运行的数量、其他账号被拒绝的行为，以及从查看器返回工作台的路径。迁移后保留私有原件，以供恢复。[查看器安装与观察数据格式](POLARIS-VIEWER.md) · [存储与恢复](STORAGE.md)
