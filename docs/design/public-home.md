# 公开产品主页

设计与实现 · 2026-11-20 · [English](public-home.en.md) · [初版中文原型](public-home.zh-CN.html) · [初版英文原型](public-home.en.html)

## 目标与范围

通过搜索进入的人应能看懂 Praxis 是什么、看到真实的 agent → 应用过程，再选择在线试用或自托管。已有用户直接进入工作台。这是公开产品介绍页，和登录后的日常工作界面分开。

实现决定（2026-11-20）：公开主页在既有工作台 canonical origin 上线。未登录访问 origin 根路径或 `/zh-cn/` 时返回公开主页，已登录会话在 `/` 继续使用工作台。原工作台「关于 Praxis」入口及其 `/about/` 页面移除，由本主页承接内容。设计原型由 `src/public-home.mjs` 服务端渲染版本和 `public/` 静态资源取代。

## 视觉修订——恢复通栏演示

按最新确认，主标题与两个按钮放在一起，下方恢复通栏产品演示，不再使用首屏双栏。保留真实 GIF 的可读尺寸、自动播放、减少动态效果的显式控制及无 JavaScript 静态图。吸顶页头覆盖整个视口，内层使用紧凑导航；统一节间节奏。结果卡片置于原生工作台浅色画布中，将应用、出现原因、标题、到期时间、依据与主次操作分别排版，不挤在同一行。既有内容章节、授权→提问→查看结果顺序与 SEO 端点保持。

“自己的工作，自己掌握”恢复原来的左右布局：左侧标题，右侧上下排列精简后的数据/授权与操作线索两项。手机保留单列。此前删除的智能体选择说明不恢复，其他主页修改保持。

## 内容修订——注意力与精简章节

去掉演示图下方两行说明，正常自动播放时不留空白说明条；减少动态效果时保留播放/暂停，无 JavaScript 时保留动图链接。卡片定位改为 **你的注意力，由你安排。**：选择现在关注、稍后处理或收起，阅读不等于接受工作或已读回执。应用目录标题与说明上下排列。“自己的工作，自己掌握”标题下只保留数据/授权和操作线索两栏短文，删除“智能体，由你选择”。吸顶页头加入文档及参与贡献，并保持手机换行与锚点避让；英中同步。

## 视觉方向

沿用产品原生系统字体与应用图标，以白底、深色文字和松绿色操作为主。记忆点是现有真实 Paseo / Praxis 四帧演示，Reminder 使用合成内容，不重新编造聊天界面。修订（2026-11-20，已实施）：页头吸顶；首屏去掉辅助说明段落，动画示例恢复至主标题和按钮下方通栏自动播放（`prefers-reduced-motion` 时显示静态图和显式播放按钮；无 JavaScript 与分享卡使用静态图）；连接步骤为授权 → 提问 → 查看结果；应用目录之后新增结果卡片设计预览。没有虚构客户、用户量、GitHub 星数或装饰性仪表盘。

## 页面结构与文案

1. 顶部：Praxis、应用、开始使用、文档、参与贡献、GitHub、语言、打开工作台。
2. 首屏：**为你的 AI 智能体，准备一个自己的工作台。** 主标题和两个按钮独立排列，通栏动画放回下方，去掉辅助说明段落；两个入口为“用你的智能体试试”和“自行部署 Praxis”。
3. 真实演示：左侧 Paseo，右侧 Praxis；默认自动播放，`prefers-reduced-motion` 与无 JavaScript 时为静态图与显式播放控制。
4. 三步：登录授权 → 说出想要的结果 → 查看结果。强调保护使用者注意力，不承诺所有工作流已做到零点击，不引入员工监督。
5. 内置应用：十三个已发布组件的真实图标、名称、简短用途、公开源码链接；Polaris 标明运行观察，不作为业务卡片。
6. 结果卡片设计预览：展示卡片如何呈现改了什么、为什么出现，以及一键打开来源记录。
6. 自己掌握工作：自己的数据、可查的操作线索、自建应用，适用于个人、家庭、团队与组织。
7. 在线试用与自托管：分开说明，最后是始终展开的常见问题和文档入口。

在线试用复制 README 的 OAuth prompt，由用户登录并选择授权，再执行具体 Reminder 示例。明确需要已有账号，开放注册仍在计划中，不放虚假注册按钮。本地部署启动完整十三应用 Compose 栈，读取生成账号，再连接本机 MCP。实际展示目录由受审应用注册表生成，不另设权威应用清单。

## 交互与可访问性

双语页脚均使用 ©、当前年份及链接 https://www.55aaseclab.com/ 的 55AA Security Lab 版权署名，替代重复产品宣传语。



部署资源使用带内容摘要的 CSS/JavaScript 路径。HTML 及旧无版本别名重新校验，不再各自独立保持新鲜缓存；仅精确摘要资源采用 immutable 缓存，避免升级后出现已复现的 header 混排和演示间距丢失。



导航与源码使用普通链接。复制只改变固定图标槽和隐藏的无障碍播报，不插入“已复制”一行、不跳布局、不弹 toast；失败时保留可手选文本。演示有明确播放/暂停状态和可访问名称，无 JavaScript 时仍能看静态图。保留焦点、最小44px点击区域，手机应用目录为两列，正文与 FAQ 不折叠，页面不横向溢出。
